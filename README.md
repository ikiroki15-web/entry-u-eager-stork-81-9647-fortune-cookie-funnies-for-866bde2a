# Fortune Cookie Funnies for Engineers

Entry for the [Fortune Cookie Funnies for Engineers](https://make.fun/c/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a) bounty on make.fun: one fortune cookie message for a software engineer, at most 120 characters, as a single line.

## The fortune

> You will find the missing semicolon exactly one minute after blaming the framework.

83 characters, one line.

## How it works

`main.ts` (Node 22, no dependencies) reads the fortune from `fortune.txt`, validates it against the competition gate — one line, 1–120 characters, not only whitespace — and writes it verbatim to `/output/entry.txt`.

```sh
node main.ts
# wrote 83-character fortune to /output/entry.txt
```
